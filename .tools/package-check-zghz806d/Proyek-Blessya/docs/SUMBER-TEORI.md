# Sumber teori yang digunakan

Rujukan [1]–[11] tersedia pada daftar pustaka laporan. Bahan yang diperiksa:

| Sumber | Bagian yang dibaca | Penggunaan |
|---|---|---|
| OSTEP, Arpaci-Dusseau dan Arpaci-Dusseau | Bab 4, 7, 26, 28 dan 31 | Proses, scheduling, thread, lock dan semaphore |
| Dokumentasi Python 3.13 | Thread, Lock, Semaphore dan Event | API nyata, timeout dan batas jaminan urutan penunggu |
| Operating System Concepts, Silberschatz/Galvin/Gagne | Slide resmi Bab 3, slide 8–10 dan 16–17 | Keadaan proses, PCB, context switch |
| Operating System Concepts | Slide resmi Bab 5, slide 10 dan 21–23 | Kriteria scheduling dan pengaruh quantum |
| Operating System Concepts | Slide resmi Bab 6, slide 8 dan 56 | Mutual exclusion, progress, bounded waiting dan liveness |
| Modern Operating Systems edisi 2, Tanenbaum | Sampel resmi 2.2, halaman buku 81–83 | Perbedaan sumber daya proses dan alur thread |
| Dijkstra, EWD123 | Bagian 3.2 | Operasi P/V dan sifat atomiknya |

OSTEP dan dokumentasi Python diakses 24 Oktober 2026. Rujukan tambahan diakses
25 Oktober 2026 dari situs penulis/penerbit. Slide dan sampel dibaca untuk
memeriksa konsep, bukan disalin sebagai halaman laporan. Diagram keadaan proses
dibuat kembali untuk penjelasan, dengan rujukan konsep dicantumkan.

Tanenbaum dikutip untuk bagian yang benar-benar dibaca. Tidak ada bukti yang
menetapkan buku itu sebagai buku wajib mata kuliah ini; kesamaan daftar topik
tidak digunakan untuk menyimpulkan buku pegangan atau nama mata kuliah.

Data aplikasi, contoh perhitungan, screenshot, dan interval kejadian merupakan
hasil proyek. Data tersebut bukan angka yang diambil dari buku. PDF/presentasi
rujukan yang diunduh untuk dibaca tidak disertakan dalam paket penyerahan;
tautan sumber resminya tersedia pada laporan.
